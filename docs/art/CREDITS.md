# Art credits

Every third-party file the bakes read is listed here with its source and licence.

## Textures

`art/textures/reduce.py` builds the committed maps from the 1K-JPG downloads below. It turns colour maps into greyscale detail maps, so the bake scripts choose every hue.

| File | Source | Licence |
| --- | --- | --- |
| `art/textures/floor.jpg`, `floor_normal.jpg` | Concrete 044 D by ambientCG, https://ambientcg.com/view?id=Concrete044D | CC0 1.0 |
| `art/textures/wall.jpg`, `wall_normal.jpg` | Concrete 034 by ambientCG, https://ambientcg.com/view?id=Concrete034 | CC0 1.0 |
| `art/textures/cracks.png` | Asphalt 011 (opacity map, inverted) by ambientCG, https://ambientcg.com/view?id=Asphalt011 | CC0 1.0 |

ambientCG publishes all of its assets under CC0 1.0 Universal (https://docs.ambientcg.com/license/). We checked the licence on each asset page on 2026-10-07.
